# PromptForge

Turn simple ideas into expert AI prompts.

PromptForge helps users transform simple requests into structured, high-quality prompts optimized for AI models such as ChatGPT, Claude, Gemini, and more.

## Features

- Prompt Generation
- Smart Clarification Questions
- Prompt Critic
- Prompt Scoring
- Prompt Templates
- Prompt Library
- Prompt History
- Google Authentication

## Inspiration

This project was inspired by concepts learned in Google's Prompting Essentials course.

Framework used:

- Task
- Context
- References
- Evaluate
- Iterate

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
